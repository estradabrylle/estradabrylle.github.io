# Brylle Estrada — IT Portfolio

Static responsive website for GitHub Pages. No build tools required.

## Files
- `index.html` — website content
- `styles.css` — layout and styling

## Preview
Open `index.html` in a browser.

## Publish for free with GitHub Pages
1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` and `styles.css` to the repository root.
3. In Settings → Pages, enable deployment from the `main` branch and root folder.
4. Visit `https://YOUR-USERNAME.github.io` after deployment completes.

## Before publishing
- Confirm job titles, dates, degree names, and certification details.
- Update the Per Scholas training status if the program is completed.
- Project cards are marked as planned labs, not completed work. Add your own evidence after you complete each project.
- Do not publish patient information, hospital screenshots, internal network diagrams, credentials, device identifiers, or confidential employer information.
- Only list tools and skills you can confidently discuss in an interview.
- Review contact details before publishing.
