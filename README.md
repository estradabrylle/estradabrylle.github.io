# Brylle Estrada — IT Portfolio

A responsive personal portfolio website.

## Files
- `index.html` — website content
- `styles.css` — layout and styling

## Update on GitHub Pages
1. Open the `estradabrylle.github.io` repository.
2. Replace the existing `index.html` and `styles.css` with these versions.
3. Commit the changes to the `main` branch.
4. Wait a few minutes and refresh https://estradabrylle.github.io.

## Before sharing
- Verify job dates, titles, education, certification status, and descriptions.
- Only mark a project complete after doing the work and adding your own evidence.
- Do not post hospital screenshots, patient data, internal network diagrams, hostnames, IP addresses, tickets, credentials, or confidential employer information.
